# Практическая работа №7-9. PHP MVC интернет-магазин

Учебный проект интернет-магазина, реализованный по паттерну MVC (Model-View-Controller) на чистом PHP без использования фреймворков. 
Работа №9 является логическим продолжением работ №7 и №8 в этом же репозитории.

## Цель работы (ПР №9)
Добавить в MVC-магазин пользовательское состояние корзины через сессию (`session`) и отделить бизнес-операции от HTML-представления.

## Технологии
- **PHP 8+** (ООП, пространства имен, сессии)
- **HTML5 / CSS3**
- **JSON** (в качестве источника данных)
- **Git** для контроля версий

## Требования к окружению
- Установленный PHP версии 8.0 или выше.
- Терминал (командная строка).

## Как запустить проект

1. Откройте терминал в корневой папке проекта.
2. Запустите встроенный сервер PHP, указав папку `public` как корневую:
   ```bash
   php -S localhost:8000 -t public
