# Практическая работа №7-8. PHP MVC интернет-магазин

Учебный проект интернет-магазина, реализованный по паттерну MVC (Model-View-Controller) на чистом PHP без использования фреймворков. 
Работа №8 является логическим продолжением работы №7 в этом же репозитории.

## Цель работы (ПР №8)
Перевести каталог товаров с тестовых массивов на реальные данные из JSON-файлов, используя паттерн «Репозиторий». Освоить пространства имен (namespaces), автозагрузку классов и фильтрацию данных.

## Технологии
- **PHP 8.5** (ООП, пространства имен, стрелочные функции)
- **HTML5 / CSS3**
- **JSON** (в качестве источника данных)
- **Git** для контроля версий

## Требования к окружению
- Установленный PHP версии 8.0 или выше (для поддержки `str_contains` и `readonly` свойств).
- Терминал (командная строка).

## Как запустить проект

1. Откройте терминал в корневой папке проекта.
2. Запустите встроенный сервер PHP, указав папку `public` как корневую:
