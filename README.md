# Практическая работа №7-10. PHP MVC интернет-магазин

Учебный проект интернет-магазина, реализованный по паттерну MVC (Model-View-Controller) на чистом PHP без использования фреймворков. 
Работа №10 является логическим продолжением работ №7, №8 и №9 в этом же репозитории.

## Цель работы (ПР №10)
Добавить в магазин оформление заказа с серверной валидацией, отдельной моделью (DTO) данных формы, контроллером создания заказа и защитой формы (CSRF-токен).

## Технологии
- **PHP 8.5** (ООП, пространства имен, сессии)
- **HTML5 / CSS3**
- **JSON** (в качестве источника данных и хранилища для созданных заказов)
- **Git** для контроля версий

## Требования к окружению
- Установленный PHP версии 8.0 или выше.
- Терминал (командная строка).

## Как запустить проект

1. Откройте терминал в корневой папке проекта.
2. Запустите встроенный сервер PHP, указав папку `public` как корневую:
   ```bash
   php -S localhost:8000 -t public
