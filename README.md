# Практическая работа №7. PHP MVC интернет-магазин

Учебный проект интернет-магазина, реализованный по паттерну MVC (Model-View-Controller) на чистом PHP без использования фреймворков.

## Технологии
- **PHP 8+** (ООП, пространства имен не используются для простоты)
- **HTML5 / CSS3**
- **Git** для контроля версий

## Как запустить проект

1. Убедитесь, что у вас установлен PHP (версия 8.0 или выше).
2. Откройте терминал в корневой папке проекта.
3. Запустите встроенный сервер PHP, указав папку `public` как корневую:
   ```bash
   php -S localhost:8000 -t public
